# AntiOpGuard

A Minecraft plugin (1.21.4) that blocks all players from using `/op` and `/deop`. Only the console can use these commands.

## Features
- Blocks `/op`, `/deop`, and their aliases for all players (including OPs).
- Console still works normally.
- Lightweight and simple.

## Installation
1. Build or download the `.jar`.
2. Place it in your server's `plugins` folder.
3. Restart the server.
